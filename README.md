# 🚗 Carpool App System

A mobile carpool application developed to facilitate ride sharing between drivers and passengers. The application helps users arrange trips conveniently, reducing travel costs while promoting a more efficient and sustainable transportation experience.

## ✨ Features

### 🚘 Driver
- Register and manage driver profile
- Create and publish ride offers
- Set pickup and drop-off locations
- View passenger ride requests
- Accept or reject booking requests
- Manage upcoming and completed trips

### 👤 Passenger
- Register and manage passenger profile
- Search available rides
- View ride details
- Book a ride
- Track booking status
- View trip history

## 🎯 Project Objective

The Carpool App System was developed to provide a convenient platform for drivers and passengers to share rides. The application simplifies ride scheduling, booking, and trip management while encouraging cost-effective and environmentally friendly transportation.
